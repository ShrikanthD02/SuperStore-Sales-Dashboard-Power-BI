# 📊 SuperStore Sales Dashboard (Power BI)

This project is a Power BI dashboard built using SuperStore sales data to analyze business performance, customer behavior, and profitability.  
It provides actionable insights for decision-making by visualizing sales, profit, and trends across different dimensions.  

---

## 🔑 Key Features
- **Sales & Profit Trends** (2019–2020) – Monthly & yearly analysis  
- **Category & Sub-Category Insights** – Top-performing products (Phones, Chairs, Binders)  
- **Regional & State-wise Sales** – Performance across geographies  
- **Customer Segments** – Consumer, Corporate, and Home Office breakdown  
- **Ship Mode & Payment Analysis** – COD, Online, Cards with delivery insights  
- **15-Day Forecast** – Predictive sales visualization
